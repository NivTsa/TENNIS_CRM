# 🎾 TENNIS CRM — דאשבורד Streamlit

דאשבורד לניתוח נתוני שחקני מועדון טניס (נתונים **סינתטיים**), כולל חישוב
פוטנציאל תחרותי ומודל רגרסיה לינארית לחיזוי אחוז ההצלחה.

## התקנה והרצה

```bash
cd Desktop/TENNIS_CRM
pip install -r requirements.txt
python generate_data.py      # יוצר data/players_raw.csv (מתבצע גם אוטומטית)
streamlit run app.py
```

הדאשבורד ייפתח בדפדפן בכתובת http://localhost:8501

## מבנה הקבצים

| קובץ | תפקיד |
|------|-------|
| `generate_data.py` | יצירת נתונים סינתטיים + הזרקת ערכים חסרים וקיצוניים |
| `auth.py` | רישום והתחברות של מועדונים; קובץ נתונים נפרד לכל מועדון |
| `competitive_potential.py` | חישוב ציון הפוטנציאל התחרותי (0-100) מ-4 משתנים |
| `preprocessing.py` | ניקוי נתונים: השלמה, הסרת קיצונים, קידוד, נרמול |
| `model.py` | רגרסיה לינארית + מטריקות (R², Adjusted R², RMSE, MAE) |
| `theme.py` | שכבת עיצוב: פלטה, CSS, תבנית גרפים |
| `app.py` | הדאשבורד (התחברות + 5 עמודים) |

## מועדונים (multi-tenant)

בכניסה מוצג מסך **התחברות / רישום מועדון**:

- **רישום** — שם מועדון, שם משתמש וסיסמה. הסיסמה נשמרת מוצפנת
  (PBKDF2-HMAC-SHA256 עם salt ייחודי) ב-`data/clubs.json`.
- בעת הרישום נוצר **קובץ נתונים ייחודי** למועדון:
  `data/clubs/<club_id>/players_raw.csv` (דאטה סינתטית).
- כל מועדון רואה ומריץ **רק את הקובץ שלו**. כפתור "ייצר דאטה סינתטית חדשה"
  מגריל מחדש את הקובץ של אותו מועדון בלבד.
- "התנתקות" בסרגל הצד חוזר למסך ההתחברות.

מנגנון קליל לשימוש מקומי על נתונים סינתטיים — לא תחליף לאימות בענן.

### משתמש מנהל (admin)

קיים משתמש **`admin`** (סיסמה `12345`) בעל **גישה לכל המועדונים**:

- בסרגל הצד נבחר **מקור נתונים**: מועדון ספציפי, או **"כל המערכת (מצרפי)"**
  שמאחד את כל קובצי המועדונים (עם עמודת `club`).
- עמוד נוסף **"ניהול מועדונים"** — טבלת סיכום והשוואה בין כל המועדונים.
- כל שאר העמודים (סקירה/פוטנציאל/ניקוי/רגרסיה/חיזוי) פועלים על מקור הנתונים שנבחר.

ליצירת/איפוס המנהל: `python -c "import auth; auth.create_admin('admin','12345')"`

## סוגי המשתנים

| סוג | משתנים | טיפול בניקוי |
|-----|--------|--------------|
| **כמותיים** | `age`, `fitness_level` (אורדינלי 1-10), `years_playing`, `weekly_training_hours`, `height_cm` | השלמה בחציון · הסרת קיצונים ב-IQR · תקנון (StandardScaler) |
| **קטגוריאליים** | `gender`, `dominant_hand`, `backhand_type` | השלמה בשכיח · קידוד One-Hot |
| **מטרה (target)** | `success_rate` — אחוז ניצחונות | — |
| **נזרקים** | `player_id`, `full_name`, `matches_played`, `matches_won` (דליפת מטרה) | — |

`age_squared` הוא משתנה מהונדס (feature engineering) — השפעת הגיל אינה לינארית
(שיא באמצע), ולכן נוסף איבר ריבועי. המודל נשאר רגרסיה לינארית (לינארי בפרמטרים).

## הפוטנציאל התחרותי

ציון דטרמיניסטי 0-100 = סכום משוקלל של ארבעה רכיבים, לפי הבקשה:
רמת כושר, גיל (עקומת פעמון עם שיא ~25), יד חזקה (יתרון קל לשמאלים), ומין
(אפקט כמעט-ניטרלי). המשקלים ניתנים לכיוונון מהסרגל הצדדי בעמוד "פוטנציאל תחרותי".

## מודל הרגרסיה — המטריקות

- **R²** — שיעור השונות המוסברת.
- **Adjusted R²** — `1 - (1-R²)·(n-1)/(n-p-1)`, מתקנן על מספר המשתנים.
- **RMSE** — `√(mean((y-ŷ)²))`, שגיאה בנקודות אחוז.
- **MAE** — שגיאה מוחלטת ממוצעת.

כל המטריקות מחושבות על קבוצת מבחן (25% מהנתונים) שלא נראתה באימון.
